# BRCA1/2 VUS Structural Reclassification

Structural and molecular dynamics-based reclassification of variants of 
uncertain significance (VUS) in BRCA1/2, identified in a Nigerian breast 
cancer cohort (Onyia et al. 2025, PMID 40211798).

Two-stage computational pipeline: FoldX-based ΔΔG triage (Stage 1) followed 
by GROMACS molecular dynamics simulation (Stage 2), evaluated against the 
ACMG/AMP variant classification framework.

**Status:** in progress. Code and data will be archived to Zenodo with a 
DOI at manuscript submission.
